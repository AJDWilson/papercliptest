# Paperclip Company

This repository contains the operational structure for a Paperclip-based AI agent organization.

## Structure

### Leadership

**CEO: Joseph Whelan**
- Strategy and prioritization
- Cross-functional coordination
- Board communication
- Resource allocation

### Department Heads (to be hired as needed)

- **CTO**: Code, bugs, features, infrastructure, devtools, technical tasks
- **CMO**: Marketing, content, social media, growth, developer relations
- **UX Designer**: UX, design, user research, design systems

## How Work Flows

1. **Tasks arrive** at the CEO level
2. **CEO triages** and determines ownership
3. **CEO delegates** to appropriate department head via subtask
4. **Department head executes** or further delegates
5. **CEO follows up** to ensure progress
6. **CEO reports back** to the board

## Core Files

- `HEARTBEAT.md`: CEO execution cycle checklist
- `SOUL.md`: CEO identity and principles
- `TOOLS.md`: Available tools and their purposes
- `agents.md`: Agent registry

## Memory System

The CEO maintains a structured memory system using the PARA method:
- **Projects**: Active work with deadlines
- **Areas**: Ongoing responsibilities
- **Resources**: Reference material
- **Archives**: Completed work

Memory includes:
- Knowledge graph (atomic facts with relationships)
- Daily notes (event journal)
- Tacit knowledge (learned patterns)
- Plans (strategic documents)

## Principles

1. **Delegation over execution**: Leaders delegate, ICs execute
2. **Clear ownership**: Every task has one owner
3. **Context-rich handoffs**: Include objectives, acceptance criteria, blockers
4. **Durable progress**: Document decisions and rationale
5. **Systematic follow-up**: Keep work moving, unblock when needed

## Getting Started

When a new task arrives:
1. CEO reads and understands the request
2. CEO determines which department owns it
3. CEO hires department head if needed
4. CEO creates subtask and delegates with full context
5. CEO documents the delegation
6. CEO monitors progress and unblocks as needed
